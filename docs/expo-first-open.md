# Tedoku app: first-open signal (optional)

A download click is not an install. To see how many clicks turn into real installs, the app can tell the
website once, on its very first launch. The website stores only a random install id, the app version and
the OS. No name, phone number, account id, IP address or device details.

## Request format

```
POST https://YOUR-SITE.example/api/first-open
Content-Type: application/json

{ "installId": "<random uuid v4>", "appVersion": "1.0.0", "os": "android" }
```

| Field        | Rules                                                        |
| ------------ | ------------------------------------------------------------ |
| `installId`  | UUID v4, generated by the app on the device. Not linked to any account. |
| `appVersion` | Text, 1 to 32 characters (letters, digits, `.`, `+`, `_`, `-`). |
| `os`         | `"android"`, `"ios"` or `"other"`.                           |

Responses: `204` saved (or this install id was already saved), `400` invalid body, `413` body too large,
`429` too many requests from one network, `500` could not save (safe to try again next launch).
Sending the same `installId` again is harmless: it is ignored, not counted twice.

## Expo code

Install once: `npx expo install expo-secure-store expo-crypto`. Call `reportFirstOpen()` from your root
component's startup effect. Replace the URL with your deployed site (PLACEHOLDER).

```ts
import * as SecureStore from "expo-secure-store";
import * as Crypto from "expo-crypto";
import Constants from "expo-constants";

export async function reportFirstOpen() {
  try {
    if (await SecureStore.getItemAsync("tdk_install_id")) return; // already reported on an earlier launch
    const installId = Crypto.randomUUID();
    const res = await fetch("https://YOUR-SITE.example/api/first-open", {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ installId, appVersion: Constants.expoConfig?.version ?? "0.0.0", os: "android" }),
    });
    if (res.ok) await SecureStore.setItemAsync("tdk_install_id", installId); // only remember it after success
  } catch { /* no network: try again next launch */ }
}
```

Notes
- The key `tdk_install_id` is stored on the device only. If the user clears app data or reinstalls, a new id is
  made and counted again (that is what you want for "installs").
- Use `AsyncStorage` instead of `SecureStore` if you prefer; the id is random and not secret.
- Do not send user ids, emails, phone numbers or push tokens to this endpoint.
